plainmark 首个版本 —— 一个像记事本一样简单的 Markdown 编辑器。

## 下载

| 安装包 | 说明 |
|---|---|
| `plainmark_0.1.0_x64-setup.exe` | NSIS 安装程序，体积小，推荐个人用户 |
| `plainmark_0.1.0_x64_zh-CN.msi` | MSI 安装包，适合企业批量分发 |

两者均支持 **Windows 10 及以上**。

## 特性

- **像记事本**：原生菜单栏（文件 / 编辑 / 格式 / 查看 / 帮助）与状态栏，布局和快捷键对齐 Windows 记事本
- **Markdown 语法高亮**：只给源码上色，不弹预览面板，编辑面始终是纯文本
- **标签页**：一个窗口开多个文档，每个标签独立撤销历史
- **编码无损**：ANSI / UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE 打开时自动识别，保存时原样写回
- **换行符可切**：Windows (CRLF) / Unix (LF) / Macintosh (CR)，状态栏一键切换
- **右键新建**：安装后在资源管理器右键「新建」菜单直接创建 Markdown 文档
- **本地优先**：不联网、不上传，无遥测

## 安装说明

- 采用**当前用户**安装，不需要管理员权限
- 首次启动需联网下载 WebView2 运行时（Windows 11 已内置）
- 安装后自动关联 `.md` / `.markdown`，并注册右键「新建 → Markdown 文档」

## 已知限制

- 打印与页面设置尚未实现，菜单中不提供
- 字体对话框为自建界面（WebView2 无原生字体选择器），与记事本存在细微差异
- 查找 / 替换使用编辑器内置面板，尚未做成记事本的中文独立对话框
- 不接管 `.txt` 关联，避免抢占记事本的默认地位
