## 新增

### Markdown 可视化预览

右侧预览侧边栏，边写边看渲染结果。

- **可调宽**：拖动分隔条在 260–900px 之间调整，宽度与开关状态会被记住
- **可开关**：通过「查看 → 预览侧边栏」控制
- **只读**：预览里的文字不能编辑，编辑始终在左侧的纯文本区进行
- **拖拽重排**：拖动预览中的段落、列表、图片等块改变顺序，Markdown 源码同步更新
- **元素面板**：徽章、分隔线、引用块、代码块、表格、任务列表等模板，可拖入预览的指定位置，也可点击插入到光标处
- **图片拖入**：把图片文件拖进窗口，会自动复制到文档同目录的 `assets/` 下并插入引用。重名时自动加序号，不会覆盖已有文件

渲染支持 GitHub 风格的表格、任务列表、删除线，以及裸链接自动识别。渲染结果经过清洗，脚本与事件属性会被拦截。

## 变更

### 界面改为独立设计

功能仍与记事本对齐（菜单结构、快捷键、状态栏信息），但视觉换成自有设计语言，不再复刻记事本外观。

- 配色改为品牌色系（取自应用图标的靛蓝 → 紫罗兰）
- 圆角、留白、阴影体系；编辑区成为内嵌白色面板
- 标签栏：圆角标签、品牌色选中态、关闭按钮按需出现
- 状态栏：圆角胶囊字段，可点击项有明确的悬停反馈
- 对话框：圆角卡片、品牌色主按钮、淡入上浮动效
- 编辑器行高 1.2 → 1.6，内边距放宽，长时间写作更舒适

### 「查看」菜单

新增「预览侧边栏」与「元素面板」两个开关。

## 修复

- **右键「新建」菜单出现两个重复条目**：`.md` 与 `.markdown` 共用「Markdown 文档」这一个类型名，而「新建」菜单按扩展名逐条列出，两个都注册就会出现两条一样的。改为只注册 `.md`，与记事本只给 `.txt` 注册、不给 `.text` 的做法一致。`.markdown` 仍可双击打开。
- **升级安装时旧的重复注册不会被清理**：清理逻辑原先放在卸载钩子里，但升级时若选择「不先卸载」，卸载段根本不会执行，旧键会一直残留。已改到安装钩子，保证升级时一定被清掉。
- **「文件 → 退出」只关闭当前窗口**：多窗口时其余窗口仍在。现在会退出整个应用。
- **「外部改动检测」未实现**：窗口重新获得焦点时会比对文件的修改时间，若被其它程序改动则询问是否重新加载。
- **ANSI 保存时不可表示字符写成 `&#nnnn;`**：记事本写的是 `?`，现已对齐。
- 清理了若干从未被调用的方法。

## 已知限制

- 打印与页面设置尚未实现，菜单中不提供
- 字体对话框为自建界面（WebView2 无原生字体选择器），与记事本存在细微差异
- 查找 / 替换使用编辑器内置面板，尚未做成记事本的中文独立对话框
- 不接管 `.txt` 关联，避免抢占记事本的默认地位
- 预览中的远程图片（如 shields.io 徽章）会联网加载
