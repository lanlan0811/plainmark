## 下载

| 安装包 | 说明 |
|---|---|
| `plainmark_0.1.6_x64-setup.exe` | NSIS 安装程序，体积小，推荐个人用户 |

## 修复

### 查找 / 替换面板显示英文

「查找」面板此前显示的是 Find、Replace、next、match case 等英文文案。现已全部中文化：

| 原文 | 中文 |
|---|---|
| Find / Replace | 查找 / 替换 |
| next / previous | 下一个 / 上一个 |
| all | 全选匹配 |
| match case | 区分大小写 |
| regexp | 正则表达式 |
| by word | 全字匹配 |
| replace / replace all | 替换 / 全部替换 |

### 弹窗标题显示为「tauri.localhost 显示」

「转到行」等弹窗此前使用浏览器原生对话框，标题会显示网页地址（形如 `tauri.localhost 显示`），与桌面应用观感不符。

现已改为：

- **提示与确认类**：使用系统原生对话框，带中文标题与「确定 / 取消」按钮
- **「转到行」**：改用自建输入框，支持行号范围校验与回车确认

### 其他

- 「关于」对话框此前固定显示版本号 0.1.0，现改为显示实际运行版本

## 已知限制

- 打印与页面设置尚未实现，菜单中不提供
- 字体对话框为自建界面（WebView2 无原生字体选择器），与记事本存在细微差异
- 查找 / 替换使用编辑器内置面板，尚未做成记事本的中文独立对话框
- 不接管 `.txt` 关联，避免抢占记事本的默认地位
- 预览中的远程图片（如 shields.io 徽章）会联网加载
- 启动速度受限于 WebView2 运行时初始化，无法与原生记事本完全一致
