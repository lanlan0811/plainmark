## 变更

### 「关于」对话框重新设计

原先只显示版本号、一句简介和协议，信息量偏少。现在改为自建对话框，包含：

- 应用图标、名称与版本号
- 一句话简介
- **运行环境**：系统版本、架构、安装方式（exe / msi）、Tauri 版本、渲染引擎版本
- 项目主页与开源协议的直接入口

其中「安装方式」会显示你用的是哪种安装包，便于反馈问题时说明环境。

### 启动路径优化

针对启动偏慢的问题做了两项调整：

- **编译改为按速度优化**：`opt-level` 由体积优先（`s`）改为速度优先（`3`）
- **窗口尺寸收敛移出主线程**：此前在启动流程中同步调用窗口 API，会阻塞窗口出现；现改为异步执行

同时加入启动耗时埋点，可通过环境变量启用，用于定位各阶段耗时：

```
set PLAINMARK_STARTUP_LOG=1
plainmark.exe
```

> **关于启动速度的说明**：实测前端渲染仅约 200ms，耗时主要在 WebView2 运行时初始化。该运行时约 619MB / 712 个文件，启动时会拉起十余个进程；若装有安全软件（如 360），这些文件会被逐个实时扫描，显著拖慢启动。将 plainmark 安装目录加入安全软件信任区通常能明显改善。

## 已知限制

- 打印与页面设置尚未实现，菜单中不提供
- 字体对话框为自建界面（WebView2 无原生字体选择器），与记事本存在细微差异
- 查找 / 替换使用编辑器内置面板，尚未做成记事本的中文独立对话框
- 不接管 `.txt` 关联，避免抢占记事本的默认地位
- 预览中的远程图片（如 shields.io 徽章）会联网加载
- 启动速度受限于 WebView2 运行时初始化，无法与原生记事本完全一致
