## 变更

### 菜单栏改为应用内自绘

此前的菜单栏是 Win32 原生菜单，由系统绘制——灰底、全直角、方块勾选，和 Windows 记事本一模一样，既无法定制样式，也缺少自己的识别度。

现在改为应用内自绘：

- **菜单与标签合并到顶部一行**：左侧是品牌标记和「文件 / 编辑 / 格式 / 查看 / 帮助」，右侧紧接文档标签与新建按钮
- **浮层为白色圆角卡片**，悬停项用品牌浅底与靛蓝文字，勾选项显示品牌色对勾
- **功能一处未减**：菜单结构、菜单项、快捷键全部保持原样

### 快捷键与键盘操作

原生菜单的快捷键由系统注册，改为自绘后必须在前端补齐。现已支持：

| 快捷键 | 功能 |
|---|---|
| Ctrl+N / Ctrl+Shift+N | 新建 / 新建窗口 |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | 打开 / 保存 / 另存为 |
| Ctrl+F / F3 / Shift+F3 | 查找 / 查找下一个 / 查找上一个 |
| Ctrl+H / Ctrl+G | 替换 / 转到行 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小 / 恢复默认缩放 |
| F5 | 插入时间日期 |

菜单也支持键盘导航：**Alt+F/E/O/V/H** 直接展开对应菜单，方向键在菜单项之间移动，←/→ 切换相邻菜单，Esc 关闭。

### 视觉细节

- 顶部工具条加入品牌标记，标签选中态改为品牌浅底，与菜单悬停态共用一套色彩语言
- 设计令牌整体微调：圆角由 4/6/10 放大到 5/8/12，次要文字与边框的对比度略微加深
- 编辑区默认字体优先使用 Cascadia Mono

## 已知限制

- 打印与页面设置尚未实现，菜单中不提供
- 字体对话框为自建界面（WebView2 无原生字体选择器），与记事本存在细微差异
- 查找 / 替换使用编辑器内置面板，尚未做成记事本的中文独立对话框
- 不接管 `.txt` 关联，避免抢占记事本的默认地位
- 预览中的远程图片（如 shields.io 徽章）会联网加载
- 启动速度受限于 WebView2 运行时初始化，无法与原生记事本完全一致
